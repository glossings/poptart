Chapter 5

Modulation

Any control can move: LFOs, drawn shapes, envelopes, knobs.

Wherever a value goes, a moving signal can go instead. Modulation runs inside the audio engine, sample-accurate, not as a stream of messages.

LFOs

sine · saw (rises) · isaw (falls) · tri · square · rand · perlin (smooth drift). Each runs 0..1, and .range(lo, hi) rescales it.

The rate is in cycles: sine(0.25) is one pass every four cycles, aligned to the bar grid, so a slow sweep is in the same place every time round. Write a unit for a fixed speed: sine("0.5hz"). 

bass: note("c2 c2 c3 c2 eb2 c2 g2 bb1").synth("Wavetable")
  .fx("Filter").param("Mode", "ladder")
  .param("Cutoff", sine(0.25).range(0.3, 0.7))
  .param("Resonance", tri(0.5).range(0.2, 0.7))
.param("Filter 1 Freq", sine(0.3).range(200, 5000))

.range()'s bounds can move too: sine().range("0.2 0.3", 0.8)sine().range("200 300", 4000) sweeps from a stepped floor.

Drawn shapes

lfo("…", { rate, mode }) is a shape you draw. Double-click the word lfo, drag points and bend segments, and the code is written as you go. The two ends move together while they sit at the same level, which keeps a loop from clicking; alt moves one alone.

mode
freeloops on its own clock (the default)
retriggerrestarts on every note
envelopeplays once per note, then holds
pad: note("<[c3,eb3,g3] [ab2,c3,eb3]>").synth("Wavetable")
  .param("Osc 1 Table", "Vocal")
  .param("Osc 1 Position", lfo("0,0 0.5,1,-3 1,0", { rate: 0.5 }))
  .fx("Reverb")

Shapes are named, so they pattern: lfo("<pluck swell>").

Envelopes

env({ attack, decay, sustain, release, curve }) is an ADSR started by each of the track's notes. Times are in seconds, sustain is a level. 

bass: note("c2 c2 c3 c2 eb2 c2 g2 bb1").synth("Wavetable")
  .fx("Filter").param("Mode", "ladder")
  .param("Cutoff", env({ attack: 0.01, decay: 0.2, sustain: 0.1 }).range(0.25, 0.7))
kick: s("pt_kit:0*4")
.param("Filter 1 Freq", env({ attack: 0.01, decay: 0.3, sustain: 0.2 }).range(300, 6000))

dur() is the current note's length in seconds, for anything that should scale with it.
