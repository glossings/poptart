Chapter 3

Notes & scales

Absolute notes, scale degrees, and one key for the whole song.

Notes and degrees

WriteMeans
note("c4 e4 g4") · note("60 64 67")absolute pitch; c3 is MIDI 60, sharps and flats are c#4 / db4
n("0 2 4").scale("F minor")scale degrees: 0 is the root, 7 the octave above (in a seven-note scale)
keys: n("0 2 4 6").scale("F minor").synth("Wavetable")
keys: n("0 2 4 6").scale("F minor").synth("Serum 2")

A scale is "root mode": "F minor", "c dorian", "Bb mixolydian". The modes, pentatonics, blues, harmonic and melodic minor and chromatic are there, with the usual aliases.

On a note() pattern, .scale() snaps each note to the nearest one in the key: note("c4 f#4").scale("C major") plays c4 and f4. Notes from a MIDI keyboard snap the same way.

One key for the song

setscale("C minor") sets the key for the buffer, and .sc() uses it. The optional number puts the root in that octave. 

setscale("C minor")

bass: n("0 3 5").sc(3).synth("Wavetable")
  .fx("Filter").param("Cutoff", 0.4)
lead: n("0 2 4 7").sc(5).synth("FM").vel(0.7)
setscale("C minor")

bass: n("0 3 5").sc(3).synth("Serum 2")
lead: n("0 2 4 7").sc(5).synth("Diva")

The last setscale in the buffer wins everywhere, including the tracks above it, so changing key is one edit. The piano roll follows it.

tip A synth("…") with no notes plays a C3 every cycle, so a new instrument makes sound while you decide what it should play.

To move notes by scale steps rather than semitones, add an n(): .add(n(2)) is two steps up in the key. See Transforms.
