Tracks, evaluating, and where everything lives.

Tracks

The buffer is split into blocks. A block that starts with name: is a track; lines that continue it (a .fx(…) on the next line) belong to it. 

bass: note("c2 c2 g1 a1").synth("Wavetable")
  .fx("Filter").param("Cutoff", 0.45)
drums: s("pt_kit:0*4, ~ pt_kit:4 ~ pt_kit:4")
bass: note("c2 c2 g1 a1").synth("Serum 2")
drums: s("bd*4, ~ hh ~ hh")
WriteMeans
bass:a track called bass
_bass: or bass_:muted
Sbass:soloed: while anything is soloed, only soloed tracks play (mute still wins)
$:a track without a name
a line at column 0 with no labelsetup: setbpm(128), a shared const, a helper

{mod+enter} evaluates and plays, {mod+.} stops, and update in the header evaluates without starting or stopping anything. A named track has to evaluate to a pattern; if it doesn't, the console says why and what was playing keeps playing.

Time

The unit of time is the cycle, one bar of four beats. setbpm(120) is two cycles a second. A pattern string fills exactly one cycle and repeats.

Everything you write is a signal, a value that changes over time: a melody, an LFO, a single number. A melody has edges (its notes start and stop); an LFO is smooth. The same methods work on both, so .add(), .range() and .when() don't care which they are given. 

keys: n("0 2 4 <6 7>").scale("C minor").synth("Wavetable")   // a melody: edges
  .fx("Filter").param("Cutoff", sine(0.25).range(0.3, 0.8))   // an LFO: smooth
  .fx("Reverb")

Saving and sharing

  • Whatever is in the editor is autosaved as a work in progress, filed under the month (bottom of the files tab). ⤓ keeps one under a real name.
  • A comment names the pattern everywhere: // @title kick drift, // @by kai @tags techno. The files search finds it by name, tag or code (tag:techno, by:kai).
  • Every evaluation is a browser-history entry, so Back walks through what you played.
  • share (files tab) copies a link that opens the whole pattern, captured presets included. Files you added to this browser are named in the link but not carried.
  • Everything is kept in this browser's storage; the files tab's backup exports it all to one file and imports it back.
