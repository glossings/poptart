Chapter 7

The piano roll

A note pattern you draw instead of type.

lead: pianoroll().synth("Wavetable")   // double-click the word pianoroll
lead: pianoroll().synth("Serum 2")   // double-click the word pianoroll

Double-click pianoroll and the grid opens over the editor. Rolls are named (a bare pianoroll() takes its track's name), their notes are kept in a folded block at the foot of the buffer, and names pattern: pianoroll("<verse chorus>"). The panel's ▾ finds or makes rolls; ⧉ copies one.

The options are { grid, len, start }: cells per cycle, cells in the loop, and the cell the loop starts on, so { grid: 16, len: 24 } is a bar and a half of sixteenths. Drag the loop bar rather than typing them. Notes outside the loop stay drawn, dimmed and silent.

The value lane

One marker per note along the bottom. Click the lane's label to switch between vel, prob (a per-note chance) and nudge (a per-note timing offset). With the pencil, sweep across it to paint: one gesture is a crescendo. Right-click to randomize or reset.

On a sampler

Every note has a pitch, a file index and a slice, and the note / index / slice button picks which the rows show. On index, the rows are the pack's files, so pianoroll("beat").s("pt_kit")pianoroll("beat").s("bd") is a drum sequencer. On slice, the rows are the chops of the note's file.

Slice to notes: draw one long note over a break, right-click it, and it becomes one note per chop, each where its chop falls. Now the break is a rhythm you can rearrange.

What the roll writes

The note string folds to a small pill in the editor, but it is plain text: pianoroll("60,0,4 64,0,4 67,8,8", { grid: 16 }) is midi[:index[:slice]],start,length[,velocity] per note. A roll chains like note(): .scale(), .add() and the rest. 

lead: pianoroll("60,0,4 63,4,4 67,8,4 70,12,2 72,14,2", { grid: 16 })
  .synth("Wavetable")
  .fx("Delay").param("Sync", "1/8.")
